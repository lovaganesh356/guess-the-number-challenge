# Guess The Number Challenge

An interactive number-guessing web application built using HTML, CSS, and JavaScript.

## Features
- Random number generation
- Interactive number guessing
- Score and attempts dashboard
- Voice assistant using browser speech synthesis
- Live game commentary
- Restart game functionality
- User feedback interface
- Responsive design

## Technologies Used
- HTML5
- CSS3
- JavaScript

## How to Run
1. Download or clone this repository.
2. Open the project folder.
3. Open `index.html` in your browser.
4. Start playing!

## Project Goal
To make a simple number-guessing game more interactive and enjoyable through voice assistance, live feedback, and a user-friendly interface.
